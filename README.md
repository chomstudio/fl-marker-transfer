# Pattern Marker Transfer

FL Studioのパターンマーカーを、テキストとしてコピー・直接編集・別パターンへ貼り付けするためのピアノロールスクリプトです。

## 動作環境とセットアップ

ピアノロールスクリプトAPIに対応するFL Studioが必要です。外部Pythonや追加パッケージのインストールは不要です。

`Pattern Marker Transfer.pyscript`を、FL Studioのユーザーデータフォルダ内の`Settings\Piano roll scripts`へコピーしてください。必要に応じてスクリプト一覧を更新してください。

## 使い方

1. コピー元のパターンのピアノロールのスクリプトメニューから本スクリプト(`Pattern Marker Transfer`)を実行します。
2. `マーカー情報 [xxxxxxxx]`欄を選択し、`Ctrl+A`、`Ctrl+C`でコピーします。
3. **`[X]`ボタンで閉じます**。うっかりマーカー情報欄を変更したうえで`Accept`で閉じてしまうとそのパターンのマーカーの状態が変わってしまうため、変更したくないパターンでは`[X]`ボタンで閉じれば元に戻すことができます。
4. コピー先のパターンへ切り替え、ピアノロールを開いてスクリプトを再び実行します。
5. 同じ欄を`Ctrl+A`、`Ctrl+V`で上書きします。現在の通常マーカー全件が置き換わります。
6. 必要に応じて貼り付け位置オフセット値（単位は小節）を調節します。指定可能な範囲は-16～+16ですが、**マイナス値を指定するとマーカー情報が先頭から削れていく可能性があるので注意してください**。
7. Previewで確認し、`Accept`で確定します。キャンセルで起動時へ戻します。

マーカー情報欄の文字列はJSONです。見やすく展開すると以下のような感じになります。`name`や`time`を直接編集することもできます。

```json
{
  "format": "PMT-1",
  "ppq": 96,
  "mode": 0,
  "markers": [
    { "time": 0, "name": "イントロ" },
    { "time": 384, "name": "Aメロ" }
  ]
}
```

空欄や不正な入力は起動時の状態へ戻します。通常マーカーを全削除する場合は、正しいJSONの`markers`を`[]`にしてください。入力が反映されるタイミングはFL Studioに従い、入力確定やフォーカス移動が必要な場合があります。

## 注意点

- **拍子変更マーカー、スケールやキーの変更マーカーはこのスクリプトでは対象外です**。存在しても無視します。
- コピー元とコピー先のPPQが異なるデータは拒否します。
- 対象外マーカーと同じ位置への追加は拒否します。起動時から通常・対象外マーカーが同じ位置にあるパターンも、コピーはできますが内容の変更は拒否します。
- 同時刻の通常マーカーは入力上保持しますが、ホストが欠落・統合した場合は失敗として扱い、起動時への復元を試みます。
- 不正入力やAPI操作の失敗はDebugging logの`[PMT]`に記録します。ダイアログを開いたままではほかの操作ができませんので、ダイアログを閉じた後で確認してください。`[復元失敗]`が記録された場合はキャンセル後の状態を確認してください。
- 長文の入力上限や外部コピーの完全性は未確認です。
